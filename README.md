公共交通LCD模拟程序（for Windows）
本程序使用Python3.7编译，下载安装包请见release，按提示安装完即可使用。由于主程序本体没有开源，所以无需下载source code（里面是无法运行的）。
安装包已经打包运行库，现代电脑即便没有Python一般也能运行。详细使用说明请见安装后程序所在目录的word文档，在此不赘述。
本程序由于没有签名，可能被浏览器拦截，信任即可。我保证程序没有任何恶意代码，除检测更新功能外程序完全本地运行，不会泄露任何隐私信息。
目前本程序包含成都主城区的两个风格，此部分代码开源，您可以在尊重作者著作权的前提下修改。同时程序预留了接口，您有Python基础的话也可以自己编写其他城市的风格脚本。
